# Six Participant Negotiation

판매팀 3명과 구매팀 3명이 가격·보증·배송·향후 거래 조건을 협상하는 샘플입니다.

## 실행

1. 빈 GameObject에 `SixParticipantNegotiationExample`을 추가합니다.
2. Play Mode에 들어갑니다.
3. 컴포넌트 컨텍스트 메뉴에서 **Advance Negotiation**을 실행합니다.
4. Console에서 현재 화자, 발화, 다음 화자, 종료 이유를 확인합니다.

샘플은 외부 LLM을 호출하지 않습니다. 고정 발화를 제출해 런타임 통합 흐름만 재현합니다.
